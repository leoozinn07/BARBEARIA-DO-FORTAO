# Barbearia do Fortão

App de agendamento da Barbearia do Fortão, na Cohab 5 (São Paulo): site e app Android com login por e-mail e senha, painel do Fortão para a agenda, lembretes por e-mail e notificações.

## Andamento

| Etapa | O que é | Status |
| --- | --- | --- |
| 1. Landing page | Três opções de página inicial mobile para escolher | Pronta para escolha em [`prototipos/landing-mobile`](prototipos/landing-mobile) |
| 2. App completo | HTML, CSS e JS semânticos + Node e MySQL: contas, agendamento, painel, e-mails, LGPD | Aguardando a escolha da etapa 1 |
| 3. Play Store | PWA empacotado como app Android (Trusted Web Activity) | Depois da etapa 2 |
