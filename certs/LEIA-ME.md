# Certificado do banco

Coloque aqui o certificado do Supabase com o nome `supabase-ca.crt`.

Onde baixar: painel do Supabase > projeto **barbearia-do-fortao** > Database > Settings > SSL Configuration > **Download certificate**.

Ele é público (não é senha) e serve para o site conferir que está falando com o banco certo, com a conexão criptografada.
